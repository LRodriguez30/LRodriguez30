# Proyectos

## Musex

**Reproductor y gestor de música local para Windows.**

Musex es uno de mis proyectos personales más completos. Está diseñado como un entorno local para administrar, reproducir y organizar música, evitando depender de una infraestructura propia en la nube.

### Tecnologías

* Angular
* TypeScript
* Rust
* Tauri
* Tailwind CSS

### Características

* Biblioteca musical local
* Reproducción de audio
* Cola de reproducción
* Favoritos
* Historial
* Descarga de audio
* Gestión de metadatos
* Carátulas
* Ecualizador paramétrico
* Exploración y recomendaciones
* Musex Sense
* Almacenamiento local
* Integración con herramientas externas

El proyecto también me ha permitido trabajar con procesamiento de audio, filesystem, comandos entre Rust y Angular, empaquetado de aplicaciones Windows y arquitectura de aplicaciones de escritorio.
